# Flint Block Slab
## This mod adds a slab variant for the Block of Flint from Supplementaries!

That's it. That's all it adds.


**For context:** I was playing the Create mod and noticed that I really liked the look of the Flint Block underneath my train tracks. I set my Mechanical Rollers to pave wth them, and then was dismayed when they didn't have a slab variant to pave with! Ergo, this mod adds the slab variant in question! And nothing else.
